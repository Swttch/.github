<h1 align="center">Swttch</h1>

<p align="center"><strong>A GUI for CLI coding agents.</strong></p>

<p align="center">
  Work with Claude Code in your JetBrains IDE or browser.<br />
  Keep your conversations, tools, and code context together.
</p>

### Our projects

| Project | What you can do |
| --- | --- |
| [Swttch](https://github.com/Swttch/swttch) | Use Claude Code through a graphical interface in JetBrains IDEs or your browser. |
| [Extend Kit](https://github.com/Swttch/extend-kit) | Access Claude Code account and usage information, and speech-to-text, through companion tools usable on their own. |
